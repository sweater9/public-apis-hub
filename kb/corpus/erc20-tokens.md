# ERC-20 Tokens

ERC-20 is the common fungible token standard on Ethereum and many EVM chains. It defines functions like transfer, approve, and transferFrom. Almost all DeFi tokens follow it or a compatible variant.

Because any contract can claim to be a token, verify the contract address from official project channels. Decimals, fees-on-transfer, and rebase mechanics can break naive integrations.
