# Core Banking and Ledgers

**Core banking** systems keep the system of record for accounts, balances, products, and interest.

Fintechs either:
- Integrate to a bank’s core via BaaS APIs, or
- Run a **ledger** product that mirrors balances while a partner bank holds the regulatory deposit account

Identifiers:
- **IBAN** — international bank account number
- **BIC/SWIFT code** — bank identifier for cross-border
- **Routing number + account number** — US ACH/wire addressing
- **Sort code + account** — UK

**Immutable ledgers**, double-entry bookkeeping, and end-of-day batch vs real-time posting matter for reconciliations and audits.
