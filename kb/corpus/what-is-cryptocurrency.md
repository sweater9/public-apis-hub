# What Is Cryptocurrency?

Cryptocurrency is digital money that uses cryptography and a shared ledger (usually a blockchain) so no single bank or company has to approve every transfer. Users hold private keys that control funds; transactions are broadcast to a network of computers that agree on a common history.

Key properties most cryptocurrencies aim for:
- **Scarcity and rules encoded in software** (e.g. Bitcoin’s fixed supply schedule)
- **Permissionless access** — anyone can create a wallet and send value
- **Transparency** — many chains publish every transfer publicly
- **Finality after confirmations** — once enough blocks build on a transfer, reversing it is extremely hard

Cryptocurrencies are volatile, can be lost if keys are lost, and are used for payments, savings, DeFi, NFTs, and speculation. They are not the same as central bank digital currencies (CBDCs), which are issued by governments.
