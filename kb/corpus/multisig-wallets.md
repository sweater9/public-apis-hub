# Multisig Wallets

Multisignature wallets require M-of-N signatures (e.g. 2-of-3) to move funds. They reduce single-key failure and are common for treasuries. Setup complexity is higher; test recovery paths. On Bitcoin, native multisig scripts differ from Ethereum smart-contract multisigs.
