# What Is a Rug Pull?

A rug pull is when project insiders extract value and leave holders with worthless tokens — for example removing liquidity, dumping allocations, or disabling sells via malicious code.

Red flags: anonymous teams with huge unlocks, locked UI with unverified contracts, guaranteed returns, and pressure to ape in. Audit badges can be faked; read the actual findings.
