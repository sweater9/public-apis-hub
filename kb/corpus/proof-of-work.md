# Proof of Work (PoW)

Proof of Work asks miners to expend computational effort finding a nonce so that a block hash meets a difficulty target. Honest miners extend the heaviest valid chain; rewriting history requires redoing that work.

Pros: battle-tested security model (Bitcoin), objective cost to attack. Cons: energy use, specialized hardware (ASICs on many coins), slower finality than some PoS designs.

Difficulty adjusts so blocks arrive on a target schedule even as hashpower changes.
