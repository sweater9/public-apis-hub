# How to Evaluate a Crypto Project

Check: clear problem/solution, real usage metrics, transparent token distribution, audit history, team accountability, realistic roadmaps, and community quality. Prefer primary sources (docs, on-chain data) over hype threads. If returns are "guaranteed," walk away.
