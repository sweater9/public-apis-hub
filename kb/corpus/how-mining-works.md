# How Cryptocurrency Mining Works

In Proof of Work systems, miners compete to assemble a valid block and find a hash below the network difficulty. Winners earn the block subsidy plus transaction fees.

Steps in rough outline:
1. Collect pending transactions into a candidate block
2. Hash the block header repeatedly while changing a nonce
3. When a valid hash is found, broadcast the block
4. Other nodes verify and build on it

Profitability depends on coin price, fees, electricity cost, hardware efficiency, and network difficulty. Mining does not "create free money"; it sells security work to the network in exchange for issuance and fees.
