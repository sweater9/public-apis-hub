# Glossary: Address

An **address** is an identifier that can receive cryptocurrency. Formats differ (Bitcoin bech32, Ethereum 0x-hex, etc.). Sending to the wrong network or mistyped address can permanently lose funds. Always copy-paste carefully and verify the first/last characters on device screens.
