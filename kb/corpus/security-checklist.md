# Personal Crypto Security Checklist

- Back up seed offline; never store it in cloud photos or email
- Use a hardware wallet for meaningful savings
- Separate "degen" hot wallet from long-term vault
- Verify URLs and contract addresses from multiple sources
- Enable exchange 2FA (prefer app/hardware over SMS)
- Keep devices updated; avoid random WalletConnect prompts
- Test small transfers before large ones
- Plan for device loss and inheritance
