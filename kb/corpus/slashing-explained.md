# What Is Slashing?

Slashing is a protocol penalty that destroys or confiscates part of a validator’s stake for severe misbehavior — for example double-signing or surrounding votes that threaten consensus safety.

Ordinary downtime usually causes smaller missed-reward penalties, not full slashing (rules vary by chain). To reduce slashing risk: never run the same validator keys in two places, use reputable clients, and understand anti-slash protection features carefully (they are not magic).
