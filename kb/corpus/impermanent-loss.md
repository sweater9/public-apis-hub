# Impermanent Loss

Impermanent loss (IL) is the difference between holding tokens in an AMM pool versus simply holding them in a wallet, when relative prices change. Fees may offset IL, but not always.

IL is "impermanent" only if prices return; if you withdraw after a big move, the loss is realized. Concentrated liquidity and volatile pairs amplify IL. Model scenarios before providing liquidity.
